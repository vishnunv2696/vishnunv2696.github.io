## 🌟 Highlights & Portfolio Architecture

- **Interactive Global Footprint:** Built with **D3.js (v7)** and **TopoJSON**, mapping production deliveries across US Electric Utilities (Texas & New Mexico) and India (Kerala, Pune, Bangalore) with semantic zoom and project camera links.
- **Enterprise Case Studies:** 8 in-depth case studies with real-time keyword search, domain filters, and interactive modal inspection.
- **FME Interactive Data Catalog:** Embedded Leaflet + Chart.js self-documenting data intake portal.
- **AI-Assisted GIS R&D:** 5 working **Model Context Protocol (MCP)** prototypes connecting Claude AI to ArcGIS Pro (`arcpy`), QGIS (`PyQGIS`), FME Form, and PostgreSQL / PostGIS.
- **LinkedIn-Style Image Lightbox:** Interactive high-resolution visual viewer with 250% zoom, thumbnails, and step navigation.
- **Direct Lead Capture:** Working Google Forms API submission via background `fetch`.

## 🚀 How to Host on GitHub Pages (Free)

Hosting this portfolio on GitHub Pages takes less than 2 minutes:

### Step 1: Initialize Git and Commit
Open PowerShell or your terminal in this directory:
```bash
cd C:\Software_work\AntiGravity
git init
git add .
git commit -m "feat: initial commit of spatial data engineering portfolio"
```

### Step 2: Create a GitHub Repository
1. Go to [GitHub.com/new](https://github.com/new).
2. Name your repository (e.g., `portfolio` or `<your-username>.github.io`).
3. Set the repository to **Public**.
4. Click **Create repository**.

### Step 3: Link & Push
Run the commands provided by GitHub (replace with your repository URL):
```bash
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repo-name>.git
git push -u origin main
```

### Step 4: Enable GitHub Pages
1. In your GitHub repository, click **Settings** (top right tab).
2. On the left sidebar, click **Pages**.
3. Under **Build and deployment > Branch**, select `main` branch and `/ (root)` folder.
4. Click **Save**.
5. Your portfolio will be live at:
   ```
   https://<your-username>.github.io/<your-repo-name>/
   ```
   *(Or `https://<your-username>.github.io` if your repo is named `<your-username>.github.io`)*.
